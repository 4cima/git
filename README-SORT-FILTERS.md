## 🔧 التغييرات التقنية

### 1. Database Indexes (5 indexes جديدة)
```sql
idx_series_vote_average     -- لتسريع "الأعلى تقييماً"
idx_series_vote_count       -- للفلتر "الأكثر تقييماً"
idx_series_created_at       -- للفلتر "آخر إضافة"
idx_series_year_asc         -- للفلتر "الأقدم"
idx_series_name_ar_desc     -- للفلتر "الاسم (ي-أ)"
```

### 2. API Changes
- إضافة `vote_count` إلى validSorts
- دعم parameter `order` (ASC/DESC)

### 3. Frontend Changes
- إضافة state `sortOrder`
- توسيع `SORT_OPTIONS` من 4 إلى 8
- تحديث UI logic
