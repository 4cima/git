## ⛔ التوصيات الخطيرة (لا تنفذ)

### ⛔ 1. SRI للسكربتات الخارجية
**السبب:** سكربتات الإعلانات (Adsterra, PropellerAds) تتغير باستمرار. إذا اختلف الـ hash، المتصفح يرفض تحميل السكربت → خسارة الإيرادات بالكامل.
**البديل:** لا تفعل شيء.

### ⛔ 2. shell: false في Operations Panel
**السبب:** قد تكسر الأوامر التي تستخدم `|`, `&&`, `>`, `cd ... && ...`.
**البديل:** راجع كل أمر في `ALLOWED_COMMANDS` يدوياً قبل التغيير.

### ⛔ 3. Cursor-based Pagination
**السبب:** مستحيل تقنياً مع الترتيب بـ `popularity DESC`. الـ IDs ليست مرتبة حسب الشعبية.
**البديل:** لا تفعل شيء. OFFSET يعمل بشكل جيد مع D1.

### ⛔ 4. Normalization (تحويل JSON لجداول علائقية)
**السبب:**
- `json_each` يعمل أسرع في D1/SQLite من JOINs في هذه الحالة
- إعادة بناء 146,000 صف = أسابيع من العمل
- إعادة كتابة كل الاستعلامات (20+ ملف)
**البديل:** لا تفعل شيء.

### ⛔ 5. hreflang="en"
**السبب:** الموقع عربي فقط. إضافة hreflang لصفحة غير موجودة = عقوبة SEO من Google.
**البديل:** لا تضيف hreflang للنسخ غير الموجودة.

### ⛔ 6. Dynamic lang/dir Attribute
**السبب:** الموقع كله عربي RTL. تغيير `dir` على مستوى `<html>` سيبوظ التصميم بالكامل.
**البديل:** لا تفعل شيء.

### ⛔ 7. Color Contrast Changes
**السبب:** قرار تصميمي وليس تقني. تغيير الألوان بالتخمين قد يكسر Visual Hierarchy.
**البديل:** اتركه لفريق التصميم.

### ⛔ 8. حذف السكريبتات
**السبب:** بعض السكريبتات مستخدمة في GitHub Actions أو workflows.
**البديل:** تحقق من كل ملف يدوياً قبل الحذف.

### ⛔ 9. Rate Limit في D1
**السبب:**
- كل طلب API = قراءة + كتابة D1 (يضاعف الاستهلاك)
- يضيف latency 50-200ms لكل طلب
**البديل:** اتركه في الذاكرة (in-memory).

### ⛔ 10. CSS Bundle Split
**السبب:**
- Tailwind لا يحتاج split (utility-based)
- 49KB مضغوط = 8-12KB gzipped (مقبول)
- التقسيم اليدوي قد يكسر styling
**البديل:** لا تفعل شيء.

## ⚠️ توصيات تحتاج مراجعة

### ⚠️ 1. Service Worker
**السبب:** يحتاج اختبار شامل مع نظام الإعلانات الحالي.
**البديل:** اختبر في staging أولاً.

### ⚠️ 2. استبدال react-player بـ hls.js
**السبب:** قد يكسر دعم بعض صيغ الفيديو.
**البديل:** اختبر مع كل سيرفرات التشغيل أولاً.

### ⚠️ 3. VACUUM دوري
**السبب:** D1 لا يدعم VACUUM بنفس طريقة SQLite العادي.
**البديل:** تحقق من توافق الأمر مع D1.
